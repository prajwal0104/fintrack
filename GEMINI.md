# FinTrack Development Guidelines

## Version Control Workflow
- **Auto-Commit & Push**: After completing any requested feature additions, bug fixes, or modifications, always:
  1. Verify the changes run and compile cleanly.
  2. Stage modified files (git add .).
  3. Create a clear, descriptive commit message summarizing the changes (git commit -m "...").
  4. Push the commit to the remote repository (git push origin main).
